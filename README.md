**Copper Hearth** is an original warm-artisan bistro cooking game built with zero external dependencies using Vanilla ES Modules, procedural HTML5 Canvas 2D culinary art, and Web Audio API synthesis. Manage dual copper skillets with heat sweet-spot timing, chop aromatics on an oak block, layer four signature recipes (*Truffle Smash Burger*, *Seared Salmon Bowl*, *Golden Garlic Ramen*, and *Herb Margherita Flatbread*), and ring the brass service bell across three escalating shifts plus Endless mode.

## Run it

```sh
node serve.ts
# Open http://localhost:8080 in desktop Chrome (or generate dossier.json with:)
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
