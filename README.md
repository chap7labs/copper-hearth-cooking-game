**Yuzu & Hinoki — Sunlit Kyoto Open-Kitchen** is a top-down 2.5D Kyoto kitchen management game built with zero external dependencies using Vanilla ES Modules, procedural HTML5 Canvas 2D culinary art, and Web Audio API synthesis. Navigate three distinct spatial kitchen layouts (*Daylight Counter*, *Split Island Rush*, and *Lantern Dinner Service* plus Endless mode) with WASD/Arrows or click-to-move BFS routing, master the *Hinoki Chopping Block*, *Bincho Grill*, *Tempura Fryer*, and *Donabe Boiler*, assemble six combinable Kyoto recipes (*Yuzu Shio Ramen*, *Crispy Ebi Tempura Don*, *Charcoal Teriyaki Salmon*, *Smoky Yakitori Bento*, *Katsu Curry Plate*, and *Chilled Yuzu Soba*), and ring the brass pass bell before ticket patience runs out.

## Run it

```sh
node serve.ts
# Open http://localhost:8080 in desktop Chrome (or generate dossier.json with:)
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
